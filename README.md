# Cromulent (3.3.5)

Cromulent v1.5.2 for World of Warcraft 3.3.5a (Interface 30300): the world map shows each zone's level range, its
instances with their levels, and the fishing skill it needs, under the zone name.

- Author: **phyber** (based on ckknight's Cartographer_ZoneInfo). Project:
  [Cromulent on CurseForge](https://www.curseforge.com/wow/addons/cromulent) (licence: MIT),
  source [phyber/Cromulent](https://github.com/phyber/Cromulent). `LICENSE` is the MIT licence the project lists.
- Embedded libraries keep their own licences: Ace3 (AceAddon, AceHook, AceLocale), LibStub, and LibTourist-3.0 and
  LibBabble-Zone-3.0 by ckknight and Arrowmaster (MIT, see their files).
- Source of this copy: the `Cromulent.zip` kept in the 3.3.5a addon list
  [NoM0Re/WoW-3.3.5a-Addons](https://github.com/NoM0Re/WoW-3.3.5a-Addons) (`src/Addons`).
- Unchanged: the files are exactly as in that zip. This repository only adds this README and the licence file at the
  root, so the Temucraft launcher can install it from Git.

Install by hand: copy the `Cromulent` folder to `Interface\AddOns`.
